## Why this project exists

Expressing an AI-training preference should not require a website owner to become a crawler expert. An agent can help with the details: find the right setting, preserve existing behavior, avoid unsupported claims, and verify the public result.

This is a small, independent, open-source prompt project. It does not run a crawler-blocking service, collect your site's credentials, or represent any AI provider or standards body.
